# 实现与发布范围

围绕内容审核的五个模块提供可组合的研究实现，保持原桌面工程不变。

1. 动态输入：像素预算、真实 Q/K 二维 RoPE、局部/全局注意力、padding 隔离。
2. 分布式对比：先交换长度，双向 ring 特征通信，反向聚合远端梯度；变长 batch 的全局正例索引与 DDP 权重。
3. 细粒度数据：离线缓存和可选真实模型后端、短语抽取、检测/NMS、单属性负例、JSONL 数据校验；全图/区域/难例损失训练入口。
4. 视频：预算内按变化分数和时间覆盖选帧，帧局部/全局交互，跨视频隔离和 token packing。
5. 后训练：真实自回归采样、结果评分、固定旧策略/reference、response mask、参数更新和 checkpoint；失败回流、候选生成与 Judge 过滤使用显式接口与来源记录。

验收：CPU 模型 forward/backward、行为回归测试、多进程 gloo 的变长通信与梯度一致性、合成图片数据端到端运行、真实采样的 GRPO 更新。大模型权重和业务数据不随仓库发布；未运行的 GPU/NPU 路径如实列出。
